How to create a strong password

The single biggest factor in password strength is length. Each extra character multiplies the number of possible combinations an attacker has to try. A short password full of symbols is weaker than a long password of plain words. This generator defaults to 16 characters with all character types on, which is strong enough for almost any account.

A few habits that matter more than any single password: use a different password for every site, store them in a password manager so you don't have to remember them, and turn on two-factor authentication wherever it's offered. This tool never transmits or saves what it creates — the password exists only on your screen.
