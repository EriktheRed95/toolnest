About this random number generator

This free tool picks random whole numbers between any two values you choose. Use it to draw raffle and giveaway winners, roll custom dice, assign random order to a list, pick lottery-style numbers, or seed any decision that should be left to chance. Everything runs in your browser — nothing is sent to a server, and there's no sign-up.

The No duplicates option guarantees every number is unique, which is what you want for draws where the same entry shouldn't win twice. The Sort results option lists them low-to-high so a set of picks is easy to read.
