Hash any text in your browser

A cryptographic hash condenses any amount of text into a short, fixed-length fingerprint. Type into the box and this tool computes the SHA-1, SHA-256, and SHA-512 digests live, showing each as lowercase hexadecimal you can copy individually. Hashes are handy for verifying that a file or message hasn't changed, generating cache keys, or comparing data without storing the data itself.

Two things worth remembering: hashing is one-way, so there's no way to turn a digest back into the original, and SHA-1 is no longer safe against deliberate collisions — prefer SHA-256 or SHA-512 when integrity matters. The work uses your browser's built-in Web Crypto API, so your input never leaves the page.

Frequently asked questions

What is a cryptographic hash?
A hash function turns any input into a fixed-length string of hex digits. The same input always gives the same hash, but you cannot reverse the hash back into the input. Hashes are used for checksums, integrity checks, and fingerprinting data.
Which algorithm should I use?
SHA-256 is the modern default and a solid choice for most needs. SHA-512 produces a longer digest and is also strong. SHA-1 is included for compatibility but is considered broken for security purposes — avoid it for anything that must resist tampering.
Can I get my text back from a hash?
No. Hashing is one-way by design, so there's no decode step. It is not encryption and shouldn't be used to store recoverable data. To hash passwords for storage, use a purpose-built algorithm like bcrypt or Argon2 instead.
