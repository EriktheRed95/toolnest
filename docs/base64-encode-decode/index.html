Base64 Encode & Decode

Encode text to Base64 or decode Base64 back to text, right in your browser. UTF-8 safe, handles emoji and accents, and never sends your data anywhere.

Encode and decode Base64 the easy way

Base64 turns any text or binary data into a string of 64 plain ASCII characters that survive transports built for text — JSON payloads, data URLs, HTTP headers, and email. Paste your content and hit Encode to get the Base64 form, or paste a Base64 string and hit Decode to recover the original. This tool is UTF-8 aware, so emoji, accents, and non-Latin alphabets convert correctly in both directions.

Remember that Base64 is encoding, not encryption: it hides nothing and adds no security, since anyone can reverse it. Use it to move data safely through text-only channels, not to protect secrets. Everything here runs in your browser with no network calls, so even sensitive strings stay on your machine.

Frequently asked questions

What is Base64 encoding?
Base64 represents binary or text data using 64 safe ASCII characters (A–Z, a–z, 0–9, + and /). It's used to embed data in places that expect text, like JSON, data URLs, and email attachments. It is encoding, not encryption — anyone can decode it.
Does this handle emoji and accented characters?
Yes. The tool encodes through UTF-8 first, so emoji, accents, and non-Latin scripts round-trip correctly. Plain btoa would break on those characters, which is why we wrap it with proper UTF-8 handling.
Why did decoding fail?
If the input isn't valid Base64 — wrong characters, bad padding, or truncated data — decoding can't proceed and you'll see a warning. Check that you pasted the complete string and that it only contains Base64 characters.
