URL Slug Generator

Turn any title into a clean, SEO-friendly URL slug. Lowercases text, strips accents, and replaces spaces and symbols with hyphens. Free and instant.

Make a clean URL slug from any title

A slug is the human-readable tail of a web address — the part after the last slash that tells both people and search engines what a page is about. Type a headline or any text above and this tool generates a tidy slug instantly: it lowercases everything, strips accents down to plain letters, and replaces every run of spaces, punctuation, and symbols with a single hyphen. Leading and trailing hyphens are trimmed so the result is always clean.

Good slugs are short, descriptive, and made of real words separated by hyphens — the web standard that search engines read as distinct terms. Use them for blog posts, product pages, documentation, and anywhere you want a readable, shareable, SEO-friendly URL. The conversion runs entirely in your browser, so nothing you type is sent anywhere; just edit the text and copy the slug with one click.

Frequently asked questions

What is a URL slug?
A slug is the readable part of a URL that identifies a page, like 'best-coffee-shops' in example.com/best-coffee-shops. Good slugs are lowercase, use hyphens between words, and avoid spaces and special characters so they're clean and easy to share.
Why use hyphens instead of underscores or spaces?
Search engines treat hyphens as word separators, so 'red-running-shoes' reads as three words. Spaces get encoded as ugly '%20' sequences, and underscores aren't always treated as separators. Hyphens are the web standard for readable, SEO-friendly URLs.
Does this handle accents and special characters?
Yes. Accented letters like é or ñ are normalized to their plain ASCII form (e to n), and any run of symbols, spaces, or punctuation is collapsed into a single hyphen. Leading and trailing hyphens are trimmed for a clean result.
