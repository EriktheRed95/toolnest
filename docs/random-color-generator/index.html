Random Color Generator

Generate random colors with one click. See a swatch, HEX, and RGB for each, and copy all the HEX codes at once. Great for palettes, mockups, and placeholders.

Random colors for design and testing

A random color generator is one of those small tools that turns out to be surprisingly useful. Designers reach for it to kick-start a palette when a blank canvas feels paralyzing, developers use it to fill placeholder blocks and to give tags, avatars, or chart series distinct shades, and anyone can use it just to discover a hue they wouldn't have picked themselves. Each click here produces a fresh set generated with your browser's secure random source.

Every color comes with both its HEX code — the six-digit form like #3A7BD5 that CSS and design apps expect — and its RGB values, the red, green, and blue channels from 0 to 255. The swatch shows you the actual color, and the copy box collects all the HEX codes so you can paste a whole palette in one go.

  • Palettes — generate a batch and keep the shades you like.
  • Placeholders — fill blocks and components while building.
  • Variety — assign unique colors to tags, users, or data series.

Frequently asked questions

How are the colors generated?
Each color is picked using your browser's cryptographically secure random number generator (window.crypto), then formatted as a six-digit HEX code and its equivalent RGB values. No two clicks should ever give the same set.
What can I use random colors for?
They're handy for sparking design palettes, filling placeholder elements while building a layout, generating avatar or tag colors, testing how a UI handles different shades, or simply breaking creative block when you can't decide on a hue.
What's the difference between HEX and RGB?
Both describe the same color. HEX is a six-digit code like #3A7BD5 used widely in CSS and design tools. RGB lists the red, green, and blue channels as numbers from 0 to 255, like rgb(58, 123, 213). This tool shows both for every swatch.
Can I copy the colors?
Yes. Every generated set lists its HEX codes in a copy box — click Copy to grab them all at once, then paste straight into your CSS, design file, or notes.
