How to create a strong password

The single biggest factor in password strength is length. Each extra character multiplies the number of possible combinations an attacker has to try. A short password full of symbols is weaker than a long password of plain words. This generator defaults to 16 characters with all character types on, which is strong enough for almost any account.

A few habits that matter more than any single password: use a different password for every site, store them in a password manager so you don't have to remember them, and turn on two-factor authentication wherever it's offered. This tool never transmits or saves what it creates — the password exists only on your screen.

Frequently asked questions

Are these passwords safe?
Yes. Passwords are generated entirely in your browser using the cryptographically secure window.crypto API, and nothing is sent over the internet or stored. Close the tab and the password is gone.
What makes a password strong?
Length matters most. A 16-character password mixing upper- and lower-case letters, numbers, and symbols is extremely hard to crack. Aim for at least 12–16 characters and a unique password for every account.
Should I exclude similar-looking characters?
If you'll type the password by hand, ticking "Exclude look-alikes" removes characters like 0/O and 1/l/I to avoid confusion. If a password manager fills it for you, you can leave them in for extra strength.
