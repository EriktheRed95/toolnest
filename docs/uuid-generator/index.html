UUID Generator (v4)

Generate random RFC 4122 version-4 UUIDs in your browser. Choose how many you need and copy them all with one click. Cryptographically secure and completely private.

Generate unique identifiers instantly

A UUID (Universally Unique Identifier, also called a GUID) is a 128-bit value used to label something without needing a central authority to hand out IDs. This tool produces version-4 UUIDs, the random variety defined by RFC 4122, formatted in the familiar 8-4-4-4-12 hexadecimal pattern. Drag the slider to pick how many you want and click Generate; copy the whole batch with one button.

Because every value draws its random bytes from your browser's cryptographically secure generator, the identifiers are suitable for database primary keys, message IDs, file names, test fixtures, and anywhere else you need values that practically never collide. Nothing leaves your device — the UUIDs are created locally and are gone as soon as you close the tab.

Frequently asked questions

What is a version-4 UUID?
A version-4 UUID is a 128-bit identifier where almost all bits are random. It's written as 32 hexadecimal digits in the 8-4-4-4-12 pattern, with version and variant bits fixed by RFC 4122. With 122 random bits, the chance of two colliding is vanishingly small.
Are these UUIDs cryptographically random?
Yes. The random bytes come from window.crypto.getRandomValues, the browser's cryptographically secure generator. Everything happens locally, so no UUID is ever sent to a server or stored.
Can I use these as database keys or API tokens?
UUIDs are great as primary keys and request IDs where you need uniqueness without coordination. For security tokens they're acceptable given 122 bits of entropy, though a dedicated secret generator is often clearer for that purpose.
