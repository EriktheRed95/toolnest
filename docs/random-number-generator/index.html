About this random number generator

This free tool picks random whole numbers between any two values you choose. Use it to draw raffle and giveaway winners, roll custom dice, assign random order to a list, pick lottery-style numbers, or seed any decision that should be left to chance. Everything runs in your browser — nothing is sent to a server, and there's no sign-up.

The No duplicates option guarantees every number is unique, which is what you want for draws where the same entry shouldn't win twice. The Sort results option lists them low-to-high so a set of picks is easy to read.

Frequently asked questions

How do I generate a random number between 1 and 100?
Set the minimum to 1 and the maximum to 100, leave the count at 1, and press Generate. You'll get one whole number from 1 to 100, including both ends.
Can I generate numbers without duplicates?
Yes. Tick "No duplicates" and the tool will draw unique numbers. This is useful for raffles, lottery picks, or assigning unique IDs. If you ask for more numbers than the range allows, it will tell you.
Are the numbers truly random?
They are generated in your browser using JavaScript's pseudo-random generator, which is fine for games, draws, picking winners, and everyday use. It is not certified for gambling or cryptographic purposes.
