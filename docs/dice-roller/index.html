From board games to tabletop RPGs

Standard board games use the familiar six-sided die (d6), but tabletop role-playing games like Dungeons & Dragons rely on a whole set: the four-sided d4, eight-sided d8, ten-sided d10, twelve-sided d12, and the iconic twenty-sided d20, plus the d100 for percentile rolls. This tool covers them all.

If you're new to the notation, it's simple: 2d6 means "roll two six-sided dice and add them," while d20 means a single twenty-sided die. The first number is the quantity, and the number after the "d" is the sides. Match those two fields above to any roll your game calls for, and let the dice decide.

Frequently asked questions

Is this dice roller random?
Yes. Each die uses your browser's cryptographically secure random generator, so every face has an equal chance and rolls are independent. It behaves like fair physical dice, with no bias toward any number.
What dice can I roll?
Any combination you like — set the number of dice and the number of sides. Common tabletop dice are d4, d6, d8, d10, d12, and d20, but you can enter any number of sides for custom games or unusual needs.
Can I roll multiple dice at once?
Yes. Choose how many dice to roll and the tool rolls them together, showing each individual result plus the combined total — exactly what you need for tabletop games that call for rolls like 3d6 or 2d20.
What does notation like 2d6 mean?
In tabletop gaming, '2d6' means roll two six-sided dice and add them together; 'd20' means one twenty-sided die. The first number is how many dice, the 'd' stands for die, and the second number is the sides. Set those two values above to match any notation.
