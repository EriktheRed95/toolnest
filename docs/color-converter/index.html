Frequently asked questions

What's the difference between HEX, RGB, and HSL?
All three describe the same color. HEX is a six-digit hexadecimal code (#0f766e). RGB lists red, green, and blue from 0–255. HSL uses hue (0–360°), saturation, and lightness as percentages, which makes it easier to tweak a color by feel.
Can I use these values in CSS?
Yes. The HEX, rgb(), and hsl() strings shown here are all valid CSS color values. Copy whichever format your stylesheet prefers — modern browsers accept all three interchangeably.
Does the color picker stay in sync with the hex field?
Yes. Typing a valid hex code updates the picker, swatch, and RGB/HSL values, and choosing a color from the picker updates the hex field. They always reflect the same color.
